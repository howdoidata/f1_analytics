# Implementation Notes

Status: Historical evidence.

This directory stores concise notes from completed execution handoffs.

Each note should identify the handoff, files changed, validation performed, issues encountered, and any deviations from the handoff.

## Standard Format

Each future implementation note should include:

* Handoff ID and status.
* User-facing summary in plain language.
* Files changed, grouped by purpose.
* Commands run and whether they passed.
* Generated outputs and where to inspect them.
* Data assumptions and source/cutoff definitions.
* Known limitations.
* Follow-up recommendations.
